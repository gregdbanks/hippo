# Hippo

Local Tauri 2 desktop app for viewing, editing and adding Claude Code and Cursor config files under `$HOME`, with size gauges based on each tool's documented limits.

**App name**: Hippo (bundle ID `com.gregbanks.hippo`). `npm run build` installs `Hippo.app` to `$HIPPO_INSTALL_DIR` (default `~/Desktop`).

## Tech stack
- Tauri 2 (Rust backend + web frontend), React 18, React Router 6 (hash router), TypeScript 5 strict, Vite 5
- Styling: `src/client/styles.css` on top of Pico CSS. Dark theme only.
- Tests: `cargo test --lib` (Rust, uses `tempfile`), `vitest` for `src/client/lib`

## Structure
```
src-tauri/src/
  util/config_paths.rs   classify(home, path) -> (Tool, Kind). Also the write allowlist via is_editable().
  util/inventory.rs      Scans global + project config, decides how each file loads, computes per-project session load
  util/budget.rs         Documented size limits (lines/bytes/chars) and warn/over levels
  util/frontmatter.rs    Minimal YAML frontmatter reader (flat keys, folded/literal blocks)
  util/memory.rs         Lists memories for a ~/.claude/projects/<slug>/memory folder
  util/unity.rs          AGENTS.md -> CLAUDE.md links and .claude/rules -> .cursor/rules mirroring (marker-based)
  util/alerts.rs         What needs attention, transition-only notifications, daily digest rules
  util/safe_write.rs     Atomic save that keeps permissions and follows symlinks to their target
  util/history.rs        Last 20 versions of each file, saved before every save or delete
  util/guides.rs         Private guides from the app data folder, images inlined
  commands/inventory.rs  inventory
  commands/files.rs      read_file, write_file (mtime conflict check, JSON validation, symlink-safe atomic save), create_config_file, delete_file
  commands/memories.rs   get_memories, create_memory, sync_memory_index (append-only)
  commands/unity.rs      share_with_cursor, mirror_rules_to_cursor
  commands/alerts.rs     background check every 5 minutes, tray count, get_alerts, set_alerts_enabled
src/client/
  hooks/useInventory.tsx shared inventory state + refresh
  pages/                 Overview, ToolView (Claude / Cursor tabs), SkillsPage, SearchPage, MapPage, GuidesPage, Editor, MemoryBrowser, HelpPage
  tours/                 How it works tours (tours.json), screenshots and hotspots generated by npm run screenshots
  demo/                  Browser demo with fake Northwind data (npm run demo builds snapshot.json)
  components/            Gauge, FileList, SessionMeter, NewFileForm, CursorSync, ReferencesPanel, AlertSettings
  lib/                   types mirrored from Rust, format helpers (tested)
```

## Rules for changes
- `config_paths::classify` is the single source of truth for what Hippo may read or write. Any new file type goes there first, with tests.
- Size limits must come from Claude or Cursor docs, with the source URL in `budget.rs`. No invented thresholds.
- Never rewrite a user's `MEMORY.md`; only append missing entries or remove the exact line for a deleted file.
- Mirroring only ever updates or deletes `.cursor/rules` files that carry the `hippo:mirrored-from` marker.
- Alerts fire on transitions (a file getting worse), never on every scan. First run only records a baseline.
- Cursor rules are held to the same 200-line target as CLAUDE.md on purpose.
- Project discovery skips Desktop, Documents, Downloads and Library when scanning, to avoid macOS permission prompts. It still visits folders Claude has project memory for.
- Screenshots in the repo come only from the Northwind demo (`npm run demo`, then `npm run screenshots`). Never commit screenshots of real config files.
